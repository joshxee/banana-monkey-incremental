# User banana shape references

Supplied by the user on 2026-09-17 for this game's banana asset revision.

- `single.png`: elongated curved fruit, broad rounded belly, narrow neck and blunt blossom end.
- `bunch.png`: individual rounded fingers fan from a common stalk; staggered ends and overlap explain the bunch.
- `half-peeled.png`: pale flesh remains upright while the outer skin folds away in broad curling strips.

Use these for form and silhouette. The game assets remain original pixel art, with selective shading rather than watercolor texture or photographic speckling. The user also explicitly authorized additional palette colors to improve contrast and readability.

- `idle-reference.png`: user-supplied 192 × 16 strip, twelve 16 × 16 frames. Early frames lift the fruit slightly; later frames carry a small highlight down its body without external stars. The PNG does not specify timing. The new idle adopts one native pixel of lift and an authored 1.6-second cycle. `idle-reference-enlarged.png` is a nearest-neighbor inspection copy, generated by `tools/art/banana-reference.lua`.
